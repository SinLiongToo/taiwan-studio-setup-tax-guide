## 📖 專案特色

本工具為**零外部相依、單檔自帶樣式與邏輯**的互動式 Web 應用程式，支援手機與桌機響應式排版、深色／淺色主題切換、一鍵友善列印 PDF，完整解答個人創作者在設立工作室時最常遇到的法規、發票與稅務難題。

### 四大實戰篇章：

1. **🚦 決策篇：免稅免報稅關鍵指標**
   - 營業稅 8 萬元起徵點 vs. 20 萬元開立發票門檻精闢剖析。
   - 申請「免用統一發票（小規模營業人）」的策略優勢（每年省下 2~3 萬元記帳費）。
   - 個人創作稿費、版稅（9B 免稅額 18 萬元）與營業收入的申報邊界。

2. **📑 單據篇：發票與收據全圖鑑**
   - 實體二聯式發票、三聯式統一發票、免用統一發票收據（免稅收據）、勞務報酬單的適用對象與開立規範。
   - 企業客戶向工作室請款時「可否報帳抵稅」之完整對照圖鑑。

3. **🏡 房產篇：住宅登記與地方稅省稅訣竅**
   - 自用住宅登記為營業地址的房屋稅與地價稅變更解析（自住 1.2% vs. 營業用 3%）。
   - 「無招牌、無實體店面、無雇用員工、家中無庫存」之**爭取全戶 100% 維持自用稅率切結攻略**（免被硬切 1/6 營業用）。

4. **🛠️ 實戰篇：設立登記流程與公文拆解**
   - 經濟部「商工一站式」線上申辦五步驟流程圖解。
   - 縣市政府「商業登記核准函」與國稅局「營業人設立登記公文」雙軌解讀。
   - 🏛️ **國稅局臨櫃現場實戰問答 SOP**：籌備期填寫開業日技巧、營業額預估話術、免發票拍板定案指標。

## 💻 本地開啟與使用

本工具為純前端靜態單檔設計，完全不需安裝 Node.js 或建置流程：

1. 下載或複製本儲存庫：
   ```bash
   git clone https://github.com/SinLiongToo/taiwan-studio-setup-tax-guide.git
   cd taiwan-studio-setup-tax-guide
   ```
2. 直接點擊 `index.html` 即可在任一瀏覽器中開啟！
